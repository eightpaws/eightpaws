# Антон Коровин · ИТ-директор

20 лет в ИТ, 18 из них в управлении. Сейчас отвечаю за ИТ-контур юрлица в структуре Банка России: 2 000 пользователей, бюджет юрлица 1,5 млрд ₽, закупки по 44-ФЗ, согласование технических решений с регулятором.

**Что здесь публикую.** Не учебные проекты и не форки, а измерения, которые делал сам: цифры с указанием стенда, команд и сырых данных. Отрицательные результаты публикую наравне с положительными - они экономят время тому, кто пойдёт следом.

## Чем занимаюсь

- Инфраструктура в закрытом контуре: виртуализация, СХД, высокая доступность, резервное копирование с проверкой восстановления.
- Импортозамещение без остановки бизнеса: локализация после ухода вендоров, 0 остановок бизнес-сервисов.
- Локальный ИИ на своём железе: стенд, модели, замеры, расчёт бизнес-кейса, без выхода данных за периметр.
- Бюджет и закупки: структура OpEx и CapEx, обоснование перед руководством, экономия на 44-ФЗ.

## Принцип

Любая цифра в резюме должна иметь источник, который можно открыть. Поэтому сырые данные лежат рядом с выводами, а не вместо них.
